# KB 아파트 매매가격지수 — 월 1회 수동 갱신

1. KB부동산 데이터허브 → 통계 → 시계열 엑셀 다운로드 (월간시계열 또는 주간시계열 둘 다 가능)
   - 월간시계열: 날짜가 가로(열), '전국' 행 사용
   - 주간시계열: 날짜가 세로(행), '3.매매지수' 시트의 '전국' 열을 월평균으로 환산해 사용
2. 이 폴더(data/manual/)에 파일명 그대로 커밋 (여러 개면 파일명 기준 최신 파일이 사용됨)
3. 커밋하면 GitHub Actions가 자동으로 재빌드 → 1~2분 후 대시보드 반영

주의: 엑셀 원본은 repo(private 권장 아님 — public이어도 무방하나 라이선스 명시)와 별개로,
docs/에 배포되는 것은 전년동월비 가공값뿐이다.
주간시계열은 2008-04부터라 그 이전 구간은 기존 docs/data.js 값을 이어 쓴다.
